# Minimal resourcecompiler workspace

Not extensively tested, open an issue if something fails to compile along with the file(s).

## Downloading Locally

Ensure [DepotDownloader](https://github.com/SteamRE/DepotDownloader) is installed and available in your `PATH`, then run:

```bash
git clone https://github.com/Dota-Modding-Community/resourcecompiler --depth 1
chmod +x download.sh
./download.sh <steam_username> [steam_password]
```
